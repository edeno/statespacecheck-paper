# Exploratory scripts (not part of the figure pipeline)

These scripts are **exploratory / scaffolding**, not canonical figure generators.
They were used while developing the analysis — to pick Figure-4 time windows, to
sanity-check the real-data decoder, and to benchmark the interactive viewer — and
they write previews under `manuscript/figures/preview/`, never into the manuscript
figures.

The canonical, reproducible figures are generated by the scripts one level up:
`scripts/generate_figure0{1,2,3,4}.py` (see the repository README's
"Reproducing the paper figures" section).

| Script | Purpose |
| --- | --- |
| `find_immobile_replay_windows.py` | Search for immobile-replay time windows (Figure-4 window selection). |
| `find_continuous_wins_windows.py` | Search for windows where the Continuous model "wins". |
| `sanity_check_figure04a.py` | Preview real-data diagnostics for Figure-4 development. |
| `sanity_check_figure04b.py` | Preview per-window diagnostics for Figure-4 development. |
| `benchmark_figure04_viewer.py` | Performance benchmark for the interactive viewer. |

These are kept for reference and reproducibility of the exploratory process; they
may use parameters or windows that differ from the frozen choices in the canonical
`generate_figure04.py`.
